TEMPLATE KARTU — ARSIP ASET

Ini file bantu (helper) untuk isi arsip.html. Blok di bawah adalah versi kartu yang sama dengan yang tampil di halaman Arsip, cuma disusun per kategori biar gampang disalin.

CARA PAKAI:

1. Salin satu blok penuh sesuai kategorinya (dari <article sampai </article>).
2. Paste di arsip.html di dalam <div class="fd-grid" id="fdGrid">.
3. Ganti semua bagian [ ... ] dengan data asetmu.
4. Ganti src="img/thumb/..." dengan nama file gambarmu (taruh gambar di folder img/thumb/).
5. Ganti href="#" dengan link download asli (Google Drive, Mediafire, dll).
6. Hapus <span class="fd-card-badge"> kalau kartunya sudah jadi aset beneran.
7. Selesai — jumlah di hero & fdCount terhitung otomatis.

Warna tiap kategori (1 kategori = 1 warna): LOGO #e4002b · FONT #ff9a00 · PNG #ff5a75 · JPG #8a8aff
